# Lunara Front

Proyecto React + TypeScript + Vite basado en el diseño de Canva de Lunara.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir la dirección indicada por Vite, normalmente `http://localhost:5173`.

## Producción

```bash
npm run build
npm run preview
```

## Estructura

- `src/pages`: páginas principales.
- `src/components`: componentes reutilizables.
- `src/data`: contenido editable.
- `src/types`: contratos TypeScript.
- `src/styles`: estilos globales y responsive.
- `public/images`: recursos visuales extraídos del mockup.

Los testimonios son textos de demostración y deben reemplazarse por testimonios reales autorizados antes de publicar el sitio.
